## 10. SETUP FOR NEW DEVELOPERS

After cloning from GitHub, developers should run:

### Frontend Setup
```bash
npm install
npm run dev        # Starts dev server on http://localhost:8443
npm run build      # Production build
```

### Backend Setup
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
# or: source .venv/bin/activate  # macOS/Linux
pip install -r requirements.txt

# Copy .env template and fill in secrets
cp .env.example .env
# Edit .env with actual values (GEMINI_API_KEY, etc.)

# Initialize database
python scripts/init_db.py

# Run server
python -m uvicorn app.main:app --reload --port 8000
```
